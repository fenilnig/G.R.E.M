G.R.E.M. - GRADING, RENDERING & EDITING MACHINE
Deadline: Tuesday 27 Oct 2026

WHAT IT IS
ESP32-S3 (N16R8) console with a 3.12" SSD1322 OLED (256x64), 3x3 MX keys, 4 small dials + 1 large haptic dial (KY-040 modules),
coin motor + DRV2605L haptics, MCP23017 I/O expander. Power: 18650 + protected TP4056 USB-C charger + XL6009 boost set to 5.0 V.
Wireless BLE keyboard plus native USB HID.

PIN PLAN (Rev B)
  OLED SPI (4-wire): CS 10, MOSI 11, CLK 12, DC 13, RST 14
  I2C: SDA 8, SCL 9   (DRV2605L 0x5A, MCP23017 0x20)
  Encoders (A/B): 4+5, 6+7, 15+16, 17+18, 1+2
  9 keys + 5 encoder buttons on the MCP23017; interrupt -> GPIO 21

POWER RULES
  - XL6009 output set to 5.0 V with a multimeter BEFORE connecting the ESP32 (feeds ESP32 5V pin only).
  - KY-040, MCP23017 and DRV2605L run from 3V3.
  - TP4056 has no power-path: switch the rocker OFF while charging; rocker off before plugging ESP32 USB.
  - BLE only (no classic Bluetooth).
